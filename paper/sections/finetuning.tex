\section{Task-Aligned Fine-Tuning}
\label{sec:finetuning}
We fine-tuned Qwen3.5-4B with LoRA~\cite{lora} to examine adaptation to JET's
decision format. Training updates a small set of parameters while keeping the
pretrained weights frozen. The reference and adapted models both use the
mean-token candidate-scoring method at evaluation.

\subsection{Training Method}
The training mixture contains 22,791 records: 9,427 BoolQ~\cite{boolq},
2,248 ARC-Easy and 1,116 ARC-Challenge~\cite{arc}, and 10,000
SNLI~\cite{snli}. Examples use the same prompt and answer format as JET
inference, with reasoning disabled. Training minimizes next-token
cross-entropy over correct answer text. It does not directly optimize the
candidate-set softmax used for decisions.

We train 32.46 million parameters (0.77\% of the model) for one epoch, using
LoRA rank 16, a learning rate of $10^{-4}$, and an effective batch size of 16.
A separate 512-example validation subset monitors loss. Official test splits
are held out, duplicate examples are removed, and exact matches to the MMLU
evaluation questions are excluded. MMLU is not used for training or model
selection, although these checks cannot rule out paraphrases or pretraining
contamination. The completed adapter is unchanged for the new inference
evaluation; full training settings and export provenance are retained in the
repository.

\subsection{Limitations}
The reference model comes from a separate conversion, and we have not verified
that it uses exactly the same pretrained weights as the training checkpoint.
It also includes MTP weights, whereas the adapted text-only export excludes
them. Any observed accuracy difference therefore cannot be attributed entirely
to LoRA. A controlled comparison would evaluate the same checkpoint with and
without adaptation, using the same conversion procedure.

This experiment covers text-based choices only. It does not evaluate adaptation
for visual inputs, ordinal scores, or decisions in closed-loop applications.
Results on MMLU may not generalize to those tasks.
