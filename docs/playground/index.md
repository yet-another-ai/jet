# Jet playground

The playground now lives on Hugging Face Spaces:

**[Open Jet Playground →](https://huggingface.co/spaces/yet-another-ai/jet-playground)**

It runs Jet Qwen3.5 0.8B locally in your browser with WebGPU. The model downloads
to your device; your decision inputs stay in the browser.

Use a current desktop Chrome or Edge with WebGPU and enough device memory.
See the [playground guide](/guide/playground) for requirements and model links.
